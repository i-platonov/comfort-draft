# Underfloor Heating Circuit Designer

An interactive React + Vite + TypeScript tool for designing underfloor (radiant floor) heating circuits.

Features (planned):
- Import DXF floor plans as a reference layer
- Place a heating manifold
- Draw and edit heating zones
- Set per-zone pipe spacing
- Auto-generate bifilar (counter-flow) pipe spirals per zone
- Connect all zones to the manifold and compute pipe lengths

_This is the initial commit; the application is being scaffolded._
